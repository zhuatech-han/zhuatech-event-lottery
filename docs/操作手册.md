知华科技（上海如静知华信息科技有限公司） · [官网](https://www.zhuatech.cn/) · 咨询微信：`zhuatech` / `zhuatech2`

## 扫码签到

1. 在“扫码签到”填写活动名称，点击“创建签到二维码”。用另一部手机确认签到链接能够打开，再将二维码投屏或打印给参与者。
2. 参与者扫码后填写用于抽奖的姓名或编号并提交。大屏每 3 秒更新一次扫码名单，计数显示在“参与名单”中。同名只保留一人；同名不同人应补充部门或编号。
3. 人员到齐后点击“结束签到”，防止后续新名单进入奖池；需要补签时可重新开放。扫码填写不能证明本人到场，需要严格核验时应使用主办方自己的身份或票务系统。
4. 活动结束后先导出需要保留的中奖结果，再点击“删除活动”。这会删除服务端的该活动及扫码签到记录。手动名单和中奖结果仍在当前浏览器，可按需清空或重置。

## 补充名单与抽奖

1. 从 Excel 复制姓名或编号列，粘贴到“参与名单”；也可导入 CSV/TXT。TXT 每行一人；多列 CSV 需有姓名或编号列。手动名单与扫码名单合并，同名按一人处理。
2. 设置奖项名称和名额；已有中奖记录的奖项不能删除或缩减到已中奖人数以下。
3. 选择奖项，点击“开始抽奖”，再点击“停止抽奖”确定中奖者。已中奖人员不会重复进入后续抽取。
4. 点击“全屏投放”进入大屏；按 Esc 返回。结束后导出 CSV，包含奖项、姓名或编号、抽取时间。

## 背景与数据

- 在“大屏背景”选择内置主题，或上传不超过 5 MB 的 JPG、PNG、WebP 图片。可调整图片位置与压暗程度，刷新后仍保留在当前浏览器。换设备时须重新设置背景。
- 手动名单、奖项、中奖结果和活动管理凭证只保存在创建活动的浏览器。清理浏览器数据、使用无痕窗口或换设备，可能无法恢复管理权限；请及时导出结果。
- 扫码签到需要参与者手机能访问同一个站点。仅本人可访问的私有站点或电脑上的本地地址不能用于外部签到。
- 活动链接在创建后 30 天过期。过期前可由创建活动的浏览器主动删除活动及扫码记录。
- “重置结果”会清空浏览器内的中奖记录，请先导出。每场最多 2,000 个不同姓名或编号、20 个奖项。
